# CLI Alarm Clock

A lightweight, efficient command-line interface (CLI) alarm clock built purely in Python. Set alarms, manage your schedule right from your terminal, and never miss a beat!

---

## Features
* **Terminal-Based Simplicity:** Set and run alarms directly from your command line without any heavy GUI overhead.
* **Precise Time Tracking:** Built using Python's native time and datetime modules for accurate scheduling.
* **Lightweight & Fast:** Minimal resource usage, runs instantly on any system with Python installed.

---

## Tech Stack
* **Language:** Python 3.11
* **Core Modules:** `time`, `datetime`, `os` (or specific audio/notification libraries used)
